Lv.0순서쌍의 개수
orderedPair.cpp
핵심
약수 개수 세기 — O(n/2)보다 O(√n)이 더 빠름
// O(√n) 풀이
for(int i = 1; i*i <= n; i++){
  if(n % i == 0){
    answer += 2;
    if(i*i == n) answer--; // 완전제곱수 보정
  }
}
