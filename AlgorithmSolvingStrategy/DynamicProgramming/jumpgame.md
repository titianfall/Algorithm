# 외발 뛰기: JUMPGAME

> 동적 계획법(메모이제이션)으로 **도달 가능성**을 판정하는 대표 문제다. 반환 값이 참·거짓 두 가지뿐이라, 부분 문제의 답을 캐시에 저장해 두면 지수적인 완전 탐색을 다항 시간으로 줄일 수 있다.

## 문제 설명

어린 시절 즐겼던 **외발 뛰기** 놀이를 격자 위에서 한다. `n × n` 크기의 격자가 있고, 각 칸에는 1 이상 9 이하의 정수가 하나씩 적혀 있다. 게임은 격자의 **가장 왼쪽 위 칸**에서 시작하며, 목표는 **가장 오른쪽 아래 칸**에 도달하는 것이다.

각 칸에서는 그 칸에 적힌 숫자만큼 아래쪽 혹은 오른쪽으로 **정확히** 그 칸 수만큼 이동할 수 있다. 예를 들어 어떤 칸에 3이 적혀 있다면, 그 칸에서 **오른쪽으로 정확히 3칸** 떨어진 칸 또는 **아래쪽으로 정확히 3칸** 떨어진 칸으로만 움직일 수 있다. 이때 격자 밖으로 나가는 이동은 할 수 없다.

시작점에서 출발해 이동을 반복했을 때, 마지막 칸에 도달할 수 있는지 여부를 판정하라.

![외발 뛰기 격자에서 시작점에서 도착점까지 이동하는 예시](<assets/jumpgame.png>)

## 입력

입력의 첫 줄에는 테스트 케이스의 수 `C` (`1 ≤ C ≤ 50`)가 주어진다.

각 테스트 케이스의 첫 줄에는 격자의 크기 `n` (`2 ≤ n ≤ 100`)이 주어진다. 그 다음 `n`개의 줄에 각각 `n`개의 정수로 격자의 각 칸에 적힌 숫자가 주어진다. 숫자는 1 이상 9 이하의 정수이며, 마지막 칸(오른쪽 아래)에는 항상 0이 주어진다.

## 출력

각 테스트 케이스마다 한 줄을 출력한다. 시작점에서 마지막 칸으로 도달할 수 있으면 `YES`, 아니면 `NO`를 출력한다.

## 접근

### 완전 탐색으로 시작하기

현재 위치 `(y, x)`에서 마지막 칸에 도달할 수 있는지를 반환하는 함수 `jump(y, x)`를 정의하자.

```text
jump(y, x) = 시작점이 (y, x)일 때 마지막 칸에 도달할 수 있는가?
```

`(y, x)`에 적힌 숫자를 `jumpSize`라고 하면, 다음 두 가지 이동을 시도할 수 있다.

- 아래로: `jump(y + jumpSize, x)`
- 오른쪽으로: `jump(y, x + jumpSize)`

둘 중 하나라도 마지막 칸에 도달할 수 있으면 `(y, x)`에서도 도달할 수 있다.

```cpp
// 게임판의 정보
int n, board[100][100];

// (y, x)에서 시작해 마지막 칸에 도달할 수 있는지 반환
bool jump(int y, int x) {
    // 기저 사례: 게임판 밖으로 벗어난 경우
    if (y >= n || x >= n) return false;
    // 기저 사례: 마지막 칸에 도달한 경우
    if (y == n - 1 && x == n - 1) return true;

    int jumpSize = board[y][x];
    return jump(y + jumpSize, x) || jump(y, x + jumpSize);
}
```

### 중복되는 부분 문제

이 완전 탐색은 지수적으로 느리다. 아래로 한 번, 오른쪽으로 한 번 간 칸과 오른쪽으로 한 번, 아래로 한 번 간 칸이 겹칠 수 있듯이, **같은 칸 `(y, x)`에 대한 부분 문제가 여러 경로에서 반복해서 호출**되기 때문이다.

`jump(y, x)`는 입력 `(y, x)`만으로 결과가 결정되는 참조적 투명 함수다. 따라서 [메모이제이션](<explain.md>)을 그대로 적용할 수 있다.

```cpp
int n, board[100][100];
// -1로 초기화: 아직 계산 안 됨 / 0: 도달 불가 / 1: 도달 가능
int cache[100][100];

bool jump(int y, int x) {
    // 기저 사례: 게임판 밖
    if (y >= n || x >= n) return false;
    // 기저 사례: 마지막 칸
    if (y == n - 1 && x == n - 1) return true;

    // 이미 계산한 적이 있으면 곧장 반환
    int& ret = cache[y][x];
    if (ret != -1) return ret;

    int jumpSize = board[y][x];
    return ret = (jump(y + jumpSize, x) || jump(y, x + jumpSize));
}
```

`cache`는 반환 값이 `true`/`false`뿐이라 `-1`(미계산), `0`(불가), `1`(가능) 세 값으로 관리한다. `main()`에서 `memset(cache, -1, sizeof(cache));`로 초기화한다.

이처럼 동적 계획법은 
1. 주어진 문제를 완전 탐색을 통해 해결
2. 중복된 부분 문제를 한 번만 계산하도록 메모이 제이션을 적용한다.

### 시간 복잡도

메모이제이션의 시간 복잡도는 다음 식으로 계산한다.

```text
(존재하는 부분 문제의 수) × (한 부분 문제를 풀 때 필요한 반복문의 수행 횟수)
```

- 부분 문제 `(y, x)`의 개수는 격자 칸의 수와 같으므로 `O(n²)`이다.
- 각 부분 문제는 반복문 없이 상수 시간에 처리되므로 `O(1)`이다.

따라서 전체 시간 복잡도는 `O(n²) × O(1) = O(n²)`이다. `n ≤ 100`이므로 한 테스트 케이스당 최대 1만 개의 부분 문제만 계산하면 되고, 완전 탐색의 지수 시간과 비교하면 압도적으로 빠르다.
