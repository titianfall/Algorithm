## 1. 무식하게 풀기란?

컴퓨터는 사람이 하기 어려운 반복 계산을 매우 빠르게 처리할 수 있다.  
따라서 가능한 경우의 수가 충분히 작다면, 모든 경우를 하나씩 확인해서 답을 찾는 방법이 좋은 출발점이 된다.

이런 풀이 방식을 보통 다음과 같이 부른다.

- **완전 탐색**: 가능한 모든 경우를 빠짐없이 확인하는 방법
- **Brute Force**: 힘으로 밀어붙이듯 모든 후보를 검사하는 방법
- **Exhaustive Search**: 전체 탐색

완전 탐색은 가장 단순하지만, 문제의 구조를 이해하는 데 매우 강력하다.  
먼저 무식하게 풀 수 있는지 확인한 뒤, 너무 느리다면 그때 가지치기나 동적 계획법 같은 최적화를 고민하면 된다.

## 2. 재귀 호출이 필요한 이유

컴퓨터가 수행하는 작업은 대개 더 작은 작업들로 나눌 수 있다.

예를 들어 `1 + 2 + ... + n`을 구하는 문제는 다음처럼 생각할 수 있다.

```text
sum(n) = n + sum(n - 1)
sum(1) = 1
```

이처럼 큰 문제를 같은 형태의 작은 문제로 줄일 수 있을 때, **재귀 함수**를 사용할 수 있다.

- **Recursive Function**: 자기 자신을 다시 호출하는 함수
- **Recursion**: 재귀 호출

재귀는 반복문으로도 표현할 수 있는 경우가 많다.  
하지만 조합, 순열, 그래프 탐색, 백트래킹처럼 “선택하고 다음 단계로 들어가는 문제”에서는 재귀가 훨씬 자연스럽다.

## 3. 반복문으로 1부터 n까지 더하기

```cpp
int sum(int n) {
    int ret = 0;

    for (int i = 1; i <= n; i++) {
        ret += i;
    }

    return ret;
}
```

반복문 방식은 `1`부터 `n`까지 차례대로 더한다.  
흐름이 눈에 잘 보이고, 단순한 누적 계산에 적합하다.

## 4. 재귀로 1부터 n까지 더하기

```cpp
int recursiveSum(int n) {
    if (n == 1) return 1;
    return n + recursiveSum(n - 1);
}
```

재귀 함수에는 반드시 멈추는 조건이 필요하다.

```cpp
if (n == 1) return 1;
```

이 부분을 재귀 호출의 **기저 사례(base case)**라고 한다.  
기저 사례가 없으면 함수가 끝없이 자기 자신을 호출하게 된다.

단순한 반복문을 사용하는 방법과 재귀 함수를 사용하는 사례는 [pick.cpp](<pick.cpp>)에 정리했다.
